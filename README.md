# Customer Churn Prediction

Project containing dataset-agnostic churn prediction, explanation, and retention simulation.

Structure:
- `ML/` — machine learning modules, configs, data and models.
- `Backend/` — FastAPI backend and tests.
- `Frontend/` — (not present) intended for UI integration.

This repository has been refactored to be dataset-driven via YAML configs. Supported datasets: `telco`, `bank`.
